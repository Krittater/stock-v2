# StockPro mockup

ต้นแบบหน้าจอระบบคลังและเบิกจ่าย (Vue 3 + PrimeVue 4 + Tailwind ผ่าน CDN, ไม่ต้อง build) ข้อมูลทั้งหมดเป็นข้อมูลตัวอย่างเก็บใน `localStorage` ของเบราว์เซอร์

## วิธีเปิด

ดับเบิลคลิก `mockup/index.html` ต้องต่ออินเทอร์เน็ต เพราะโหลด Vue / PrimeVue / Tailwind / ฟอนต์จาก CDN

ข้อมูลเสียหรืออยากเริ่มใหม่: เมนูผู้ใช้ (การ์ดซ้ายล่าง) › **รีเซ็ตข้อมูลตัวอย่าง**

## บทบาท

กดการ์ดผู้ใช้ที่มุมซ้ายล่างเพื่อสลับ (ในเมนูเดียวกันมีสวิตช์ "ใบเบิกต้องให้หัวหน้าอนุมัติ", โหมดมืด และ "เครดิตรูปภาพ")

ทุกบทบาทเบิกของ รับของเข้า เพิ่ม/แก้วัสดุ และจัดการหมวดหมู่ได้เหมือนกัน ต่างกันแค่ตารางนี้

| บทบาท | ผู้ใช้ | ต่างจากบทบาทอื่น |
|---|---|---|
| วิศวกร | สมชาย วิศวกร | ใบรับของ (และยอดตั้งต้นตอนสร้างวัสดุ) ต้องรอ Store ยืนยันก่อนเข้าคลัง · เปิด/ปิดรอบตรวจนับไม่ได้ · ใบเบิกต้องรออนุมัติเมื่อเปิดโหมดอนุมัติ |
| Store | ก้องภพ แสงทอง | ยืนยันยอดใบรับที่วิศวกรส่ง · เปิด/ปิด/ยกเลิกรอบตรวจนับ · ใบเบิกต้องรออนุมัติเมื่อเปิดโหมดอนุมัติ |
| หัวหน้า | อรุณ รัตนชัย | ทุกอย่างของ Store + อนุมัติ/ไม่อนุมัติใบเบิก และเปิด/ปิดโหมด "ใบเบิกต้องให้หัวหน้าอนุมัติ" |

## สคริปต์เดโม (ลูปเต็ม 7 ขั้น)

เริ่มจาก "รีเซ็ตข้อมูลตัวอย่าง" ก่อน

1. **หัวหน้า** › ข้อมูลวัสดุ › แท็บหมวดหมู่ › เพิ่มหมวด "งานประปา" แล้วกด "+ หมวดย่อย" ที่แถวนั้นสร้าง "ท่อ PVC"
2. **หัวหน้า** › หน้าแรก › ทางลัด "เพิ่มวัสดุ" › ชื่อ "ท่อ PVC 1/2 นิ้ว ชั้น 8.5" เลือกหมวด "ท่อ PVC" ที่อยู่ใต้ "งานประปา" (ไม่ใช่ "ท่อ PVC" เดิมใต้ท่อและราง) หน่วย อื่น ๆ = "เส้น" ปิดสวิตช์ "มีของนี้อยู่ในคลังแล้ว" (ยอดตั้งต้น 0) › สร้าง
3. **วิศวกร** › เบิกของ › กด "ล้างทั้งหมด" ในตะกร้าก่อน (ข้อมูลตัวอย่างมีของค้างในตะกร้า 3 รายการ) › ค้นหา "ท่อ PVC 1/2" › "ดูรายละเอียด" › "เพิ่มเข้าใบเบิก (รอของเข้า)" › จำนวน 20 งาน J-25-010 › เบิกเลย ได้ "รอของเข้า" และ PR ใหม่
4. **Store** › รับของเข้า › เลือกแถว PR นั้น › ใส่ในใบรับ › จำนวน 50 › บันทึกรับของ PR ปิด ยอดคลัง 50
5. **วิศวกร** › เบิกของ › เพิ่มวัสดุเดิม จำนวน 20 › เบิกเลย ได้ "จ่ายของแล้ว" ยอดเหลือ 30
6. **Store** › ตรวจนับ › เปิดรอบนับใหม่ คลังหลัก บางนา หมวด "งานประปา" › นับได้ 28 › ปิดรอบและปรับยอด ได้ ADJ −2
7. **ทุกบทบาท** › หน้าแรก › ตารางความเคลื่อนไหวล่าสุดเห็น REQ, RC, REQ, ADJ ครบ ยอดสุดท้าย = **28 เส้น**

## ต่างจาก PDF อย่างไร

- หน้าเบิกของทำตามรูปเป้าหมาย (`docs/reference/issue-page-target.webp`): แสดงยอดคงเหลือในตารางและมีแผงตะกร้าด้านขวา ไม่มีขั้นตอนล็อก 3 ขั้นและไม่มี IF48
- เพิ่มรูปสินค้า/หมวด (PDF ข้อ 8 บอกว่าไม่ต้องมี) ผู้ใช้ขอเพิ่ม
- เมนูที่เปิดแล้วเจอหน้า "ยังไม่อยู่ในขอบเขต mockup": ขอซื้อ, โอนย้าย, รายงาน, ตั้งค่า › คลังสินค้า / โครงการ-งาน / ผู้ใช้งานและสิทธิ์
- ไม่ทำ: ติดตามม้วน (R-xxxxxx), QR/บาร์โค้ด, ออฟไลน์, ชิปสเปกสายไฟ, แท็บคืนของ

## รูปภาพ

- รูปถ่าย 8 รูปจาก Wikimedia Commons (CC0 / Public domain / CC BY) ที่ `mockup/img/photo/` และรูปวาดเอง 21 รูป (SVG) ที่ `mockup/img/draw/` ดูผู้ถ่ายและไลเซนส์ได้ที่เมนูผู้ใช้ › เครดิตรูปภาพ (ข้อมูลอยู่ใน `mockup/img/credits.js`)
- เพิ่มรูปถ่ายใหม่:
  1. `node scripts/fetch-commons.js "File:ชื่อไฟล์.jpg" mockup/img/photo/x.jpg` (ดาวน์โหลดกว้าง 320px และพิมพ์บรรทัดเครดิตออกมา ไลเซนส์ที่ไม่ผ่านเกณฑ์จะถูกปฏิเสธ)
  2. วางบรรทัดนั้นใน `mockup/img/credits.js` โดย key เป็น path ใต้ `mockup/` เช่น `img/photo/x.jpg`
  3. ตั้งเป็นรูปหมวดใน `CAT_IMAGE` ของ `mockup/js/seed.js` (หรือ `product.image` สำหรับรูปสินค้า) หรือเลือกจากหน้า ข้อมูลวัสดุ › หมวดหมู่
