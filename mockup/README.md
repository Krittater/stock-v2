# StockPro mockup

ต้นแบบหน้าจอระบบคลังและเบิกจ่าย (Vue 3 + PrimeVue 4 + Tailwind ผ่าน CDN, ไม่ต้อง build) ข้อมูลทั้งหมดเป็นข้อมูลตัวอย่างเก็บใน `localStorage` ของเบราว์เซอร์

## วิธีเปิด

ดับเบิลคลิก `mockup/index.html` ต้องต่ออินเทอร์เน็ต เพราะโหลด Vue / PrimeVue / Tailwind / ฟอนต์จาก CDN

ข้อมูลเสียหรืออยากเริ่มใหม่: เมนูผู้ใช้ (การ์ดซ้ายล่าง) › **รีเซ็ตข้อมูลตัวอย่าง**

## บทบาท

กดการ์ดผู้ใช้ที่มุมซ้ายล่างเพื่อสลับ (ในเมนูเดียวกันมีสวิตช์ "ใบเบิกต้องให้หัวหน้าอนุมัติ", โหมดมืด และ "เครดิตรูปภาพ") บัญชีใช้สิทธิ์เดียวกับวิศวกร

สิทธิ์ในหน้าหลัก 4 หน้า (คืนของ · คลังสินค้า · โครงการ / งาน · รับของเข้า) และหน้าที่เกี่ยวข้อง

| ทำอะไรได้ | วิศวกร | Store | หัวหน้า |
|---|---|---|---|
| เบิกของ | ได้ (รอหัวหน้าอนุมัติถ้าเปิดโหมดอนุมัติ) | ได้ (เหมือนวิศวกร) | ได้ และอนุมัติใบเบิกได้ |
| คืนของ | เฉพาะใบเบิกที่ตัวเองเบิก | ทุกใบเบิก + ตัดสินของที่ชั้นรอตรวจ (คืนเข้าชั้น / ตัดทิ้ง) + พิมพ์ป้ายเลขม้วน | เหมือน Store |
| รับของเข้า | ได้ แต่ใบรับรอ Store ยืนยันก่อนเข้าคลัง | ลงยอดเข้าคลังทันที และยืนยันใบรับของวิศวกร | เหมือน Store |
| คลังสินค้า: เพิ่มวัสดุ | ได้ (ยอดตั้งต้นรอ Store ยืนยัน) | ได้ (ลงยอดทันที) | ได้ (ลงยอดทันที) |
| คลังสินค้า: แก้ข้อมูลวัสดุ | แก้ไม่ได้ (ใส่รูปแรกได้) | แก้ ชื่อ ยี่ห้อ รุ่น บาร์โค้ด หมายเหตุ | แก้ได้ทุกช่อง รวมหน่วย หมวด "ต้องอนุมัติ" หน่วยตอนสั่งซื้อ จุดเตือนสั่งซื้อ · เลิกใช้วัสดุเมื่อยอดทุกคลังเป็น 0 |
| โครงการ / งาน | เพิ่ม แก้ ปิด/เปิดงาน ปิด/ยกเลิกใบเบิกได้ทุกบทบาท (ลงประวัติว่าใครทำ) | เหมือนวิศวกร | เหมือนวิศวกร |
| ตรวจนับ | เปิด/ปิดรอบไม่ได้ | เปิด/ปิด/ยกเลิกรอบ (สินค้า "ต้องอนุมัติ" รอหัวหน้า) | เปิด/ปิด/ยกเลิกรอบ |
| อนุมัติ | ไม่มีเมนู | เห็นเฉพาะแท็บ "ยืนยันยอด" (+ การ์ดหน้าแรก) | ทั้งแท็บ "ใบเบิก" และ "ยืนยันยอด" |
| ตั้งค่า › ยอดยกมา (CSV) และ ประวัติการใช้งาน | ไม่มีเมนู | ไม่มีเมนู | ได้ |

## สคริปต์เดโม (14 ขั้น)

เริ่มจาก "รีเซ็ตข้อมูลตัวอย่าง" ก่อน ขั้น 1-7 เป็นลูปหลัก ขั้น 8-14 ใช้ข้อมูลตัวอย่างที่เตรียมไว้ให้แล้ว

1. **หัวหน้า** › ข้อมูลวัสดุ › แท็บหมวดหมู่ › "เพิ่มหมวด" ชื่อ "งานประปา" › บันทึก แล้วกดปุ่ม "หมวดย่อย" ที่แถวนั้นสร้าง "ท่อ PVC"
2. **หัวหน้า** › หน้าแรก › ทางลัด "เพิ่มวัสดุ" › ชื่อ "ท่อ PVC 1/2 นิ้ว ชั้น 8.5" › หมวดหมู่ "เลือกหมวดหมู่" เลือก "ท่อ PVC" ที่อยู่ใต้ "งานประปา" (ไม่ใช่ "ท่อ PVC" เดิมใต้ท่อและราง) › หน่วย "อื่น ๆ" พิมพ์ "เส้น" › ปิดสวิตช์ "มีของนี้อยู่ในคลังแล้ว" (ยอดตั้งต้น 0) › "สร้าง"
3. **วิศวกร** › เบิกของ › กด "ล้างทั้งหมด" ในรายการเบิก แล้วยืนยัน "ล้างทั้งหมด" (ข้อมูลตัวอย่างมีของค้างในตะกร้า 3 รายการ) › ค้นหา "ท่อ PVC 1/2 นิ้ว ชั้น" › "ดูรายละเอียด" › "เพิ่มเข้าใบเบิก (รอของเข้า)" › จำนวน 20 งาน J-25-010 › "เบิกเลย" ได้ "รอของเข้า" และ PR ใหม่ (PR-690019)
4. **Store** › รับของเข้า (มือถือ: กด "ใบรับ (1)" เปิดแผ่นล่างเพื่อใส่จำนวน) › แถว PR-690019 › "ใส่ในใบรับ" › จำนวนที่รับ 50 (สั่งไว้ 20 จึงเป็นการรับเกิน: ขึ้น "รับเกินที่สั่ง 30 เส้น ใส่เหตุผล") › ใส่ "เหตุผลที่รับเกิน" เช่น "ผู้ขายแถมให้" › "ยืนยันรับของเข้า" PR ปิด ยอดคลัง 50 ใบเบิกของวิศวกรถูกกันของไว้ให้ 20 และระบบแจ้งวิศวกร
5. **วิศวกร** › กระดิ่งมุมบนเห็นแจ้งเตือน "ของที่รอ … เข้าแล้ว" › หน้าแรก › ตารางความเคลื่อนไหว แถวใบเบิกนั้น กด "จ่ายของ" ได้ "จ่ายแล้ว" ยอดเหลือ 30
6. **Store** › ตรวจนับ › "เปิดรอบนับใหม่" คลังหลัก บางนา หมวด "งานประปา" › "เปิดรอบนับ" › นับได้ 28 › "ปิดรอบและปรับยอด" (กดซ้ำในกล่องยืนยัน) ได้ ADJ −2
7. **ทุกบทบาท** › หน้าแรก › ตารางความเคลื่อนไหวล่าสุดเห็นใบเบิก (REQ) ใบรับ (RC) และ ADJ ของขั้นข้างบน ยอดสุดท้าย = **28 เส้น**
8. **Store** › คืนของ (ของเสียหาย → ชั้นรอตรวจ) › เลือกใบเบิก REQ-690013 (เบรกเกอร์ 1P 16A) › จำนวนคืน 2 สภาพ "เสียหาย" › "บันทึกคืนของ" › แท็บ "ชั้นรอตรวจ (1)" แถวนั้นยังไม่นับเป็นของพร้อมเบิก › กด "คืนเข้าชั้น" (หรือ "ตัดทิ้ง") เลือกชั้น แล้วกด "คืนเข้าชั้น" ในกล่อง ยอดคลังบวกกลับ 2
9. **Store** › คืนของ (สายม้วน) › เลือกใบเบิก REQ-690022 (สายไฟ THW สีแดง 35 ม. ที่ตัดจากม้วน R-000019) › จำนวนคืน 5 › แผงขวาบอก "จะสร้างม้วนใหม่ … อ้างอิง R-000019" › "บันทึกคืนของ" ได้ม้วนใหม่ (R-003591) กด "พิมพ์ป้ายเลขม้วน" (ปุ่มนี้เห็นเฉพาะ Store/หัวหน้า)
10. **Store** › รับของเข้า (รับแล้วแจ้งผู้เบิก) › แถวเทปพันสายไฟ PVC 3/4 นิ้ว PR-690018 › "ใส่ในใบรับ" › "ยืนยันรับของเข้า" กล่องผลบอก "ใบเบิกที่รอของนี้ได้ของแล้ว (แจ้งผู้เบิกแล้ว)" ใบ REQ-690023 กลายเป็น "รอของเข้า — กันของไว้แล้ว"
11. **หัวหน้า** › โครงการ / งาน › เลือก J-25-010 › ใบเบิกที่ยังไม่ปิดต้องจัดการก่อน: ใบ REQ-690019 (รออนุมัติ) กด "ยกเลิก" แล้ว "ยกเลิกใบเบิก" ในกล่อง · ใบ REQ-690023 กด "ปิดใบเบิก" แล้ว "ปิดใบเบิก" ในกล่อง (ค่าเริ่ม = ยกเลิกรายการต้องซื้อที่ยังไม่ได้รับของ) › กด "ปิดงาน" กล่องแสดง "ของที่ยังไม่คืน" และช่อง "ยกเลิกรายการต้องซื้อที่ยังไม่ได้รับของ" › "ยืนยันปิดงาน" (กด "ไม่ปิด" ถ้าไม่เอา)
12. **Store** (ยอดตั้งต้นของวิศวกร ≤ 2 คลิก) › หน้าแรก › การ์ด "มียอดรอคุณยืนยัน" (หรือกระดิ่ง) › แท็บ "ยืนยันยอด" แถว CC-0001 ท่อ PVC 1 1/4 นิ้ว 40 เส้น › "ยืนยันยอด" ยอดเข้าคลัง วิศวกรได้แจ้งเตือน (กด "ไม่มีของ" แล้วใส่เหตุผลถ้าไม่ผ่าน) · อยากสร้างเอง: วิศวกร › เพิ่มวัสดุ › เปิดสวิตช์ "มีของนี้อยู่ในคลังแล้ว"
13. **หัวหน้า** › ตั้งค่า › ยอดยกมา › "ดาวน์โหลดไฟล์ตัวอย่าง" แก้รหัสสินค้าแถวหนึ่งให้ผิด (หรือสร้างไฟล์ .csv เอง) › "เลือกไฟล์ .csv" แถวผิดขึ้น "ไม่พบรหัสสินค้าในระบบ (สร้างรหัสก่อน)" และปุ่ม "นำเข้ายอดยกมา" กดไม่ได้ › "ตัดแถวที่ผิด" › "นำเข้ายอดยกมา"
14. **หัวหน้า** › ตั้งค่า › ประวัติการใช้งาน เห็นขั้นข้างบนทั้งหมด ใหม่สุดก่อน กรองได้ตามผู้ใช้ การกระทำ และช่วงวันที่ · Store/วิศวกรเปิดแล้วเจอข้อความไม่มีสิทธิ์

## ต่างจาก PDF อย่างไร

- หน้าเบิกของทำตามรูปเป้าหมาย (`docs/reference/issue-page-target.webp`): แสดงยอดคงเหลือในตารางและมีแผงตะกร้าด้านขวา ไม่มีขั้นตอนล็อก 3 ขั้นและไม่มี IF48 แต่แผงเรียง ของ → จำนวน → ที่ไหน → ยืนยัน และบอก "ยังขาด: …"
- เพิ่มรูปสินค้า/หมวด (PDF ข้อ 8 บอกว่าไม่ต้องมี) ผู้ใช้ขอเพิ่ม
- เมนูที่เปิดแล้วเจอหน้า "ยังไม่อยู่ในขอบเขต mockup": ขอซื้อ, โอนย้าย, รายงาน, ตั้งค่า › คลังสินค้า / ผู้ใช้งานและสิทธิ์
- ไม่ทำ: ออฟไลน์, ชิปสเปกสายไฟ (ส่วนติดตามม้วน คืนของ และสแกน ทำแล้ว)

ที่ตัดสินใจต่างหรือเพิ่มจากสเปก:

- รับเกินที่สั่ง: เตือน "รับเกินที่สั่ง X หน่วย ใส่เหตุผล" ต้องใส่เหตุผลก่อนบันทึก (ใส่ตอน Store ยืนยันก็ได้)
- ของมาไม่มีใบขอซื้อ: รับได้ ระบบสร้างรายการต้องซื้อ (ไม่มีใบ) ให้เบื้องหลัง
- ปิดงานตอนของยังไม่คืน: ปิดได้ กล่องยืนยันแสดงของที่ยังไม่คืน
- ปิดงาน/ปิดใบเบิก: ถามว่าจะยกเลิกรายการต้องซื้อที่ยังไม่ได้รับของไหม ค่าเริ่ม = ยกเลิก
- "ต้องอนุมัติ" ตั้งที่หมวด (รวมหมวดย่อย) หัวหน้าติ๊กเองตอนสร้างสินค้าได้ · เปิดที่หมวด = ติ๊กสินค้าในหมวด · ปิดที่หมวด = ไม่ไปปลดสินค้าที่ติ๊กไว้
- เปลี่ยนหน่วย/สายม้วนของสินค้าที่มีของหรือมีประวัติแล้ว: ล็อก
- เลิกใช้สินค้าได้เมื่อยอดทุกคลัง (รวมชั้นรอตรวจและม้วน) เป็น 0 และไม่มีใบรับรอยืนยันหรือรายการต้องซื้อค้าง
- Store แก้ ชื่อ ยี่ห้อ รุ่น บาร์โค้ด หมายเหตุ · ช่องอื่นหัวหน้าเท่านั้น · วิศวกรแก้ไม่ได้ (ใส่รูปแรกได้)
- หน้า "อนุมัติ" ให้ Store เห็นเฉพาะยอดที่ต้องยืนยัน (และการ์ดหน้าแรก)
- ของที่คืนเป็นของเสียนับเป็นยอดใช้ของงาน · คืนสายม้วนที่สั้นกว่าเกณฑ์: เตือนและมีปุ่ม "เปลี่ยนเป็นของเสีย"
- วิศวกรคืนได้เฉพาะใบเบิกที่ตัวเองเบิก (ตรวจในระบบ) · นำเข้ายอดยกมาเป็นไฟล์ .csv (ไม่ใช่ Excel) · บัญชีใช้สิทธิ์เดียวกับวิศวกร
- ชั้นเริ่มต้นของ คืน / รับ / ยอดตั้งต้น = "ทั่วไป" และเลือกชั้นตอนลงยอดตั้งต้นได้
- ชื่องานซ้ำตรงตัวถูกบล็อก และกำหนดเสร็จก่อนวันเริ่มไม่ได้ (สเปกบอกว่าไม่บล็อก)
- บาร์โค้ด/รหัสผู้ขายซ้ำถูกบล็อก (สเปกบอกว่าไม่ตรวจ)
- ใช้คำไทยแทนคำเทคนิค: QC = "ชั้นรอตรวจ", batch = "ล็อตผู้ผลิต", จอง = "กันไว้ให้" (ยังมีชื่อคอลัมน์ batch ในไฟล์ CSV ตามรูปแบบไฟล์)
- ตารางแบ่งหน้าแทนปุ่ม "ดูเพิ่ม"
- ของชำรุดตอนรับนับว่ารับแล้วในรายการต้องซื้อ (อยู่ชั้นรอตรวจ) · ส่งคืนผู้ขายไม่นับ
- ยอดตั้งต้นที่รอยืนยันครอบส่วนที่ขาดของใบเบิก จึงยังไม่เปิดรายการต้องซื้อ ถ้าไม่อนุมัติจึงเปิดให้
- รายการต้องซื้อของใบเบิกปรับตามส่วนที่ขาดจริงเสมอ (ของเข้าทางอื่นแล้ว ตัดรายการที่เกิน)
- ปรับยอดจากรอบนับของสินค้า "ต้องอนุมัติ" โดยคนที่ไม่ใช่หัวหน้า รอหัวหน้าอนุมัติ · นับซ้ำ = แทนรายการเดิม
- ยกเลิกใบเบิกที่รออนุมัติ = สถานะไม่อนุมัติ + "ยกเลิกแล้ว"
- ทุกบทบาทปิดงาน/ปิดใบเบิกได้ และลงประวัติว่าใครปิด
- คืนเข้าชั้นจากชั้นรอตรวจของสายม้วนทำได้ทั้งม้วนเท่านั้น
- เพิ่มหน้า "ประวัติการใช้งาน" (หัวหน้าเท่านั้น) ที่สเปกไม่ได้ระบุ

  1. `node scripts/fetch-commons.js "File:ชื่อไฟล์.jpg" mockup/img/photo/x.jpg` (ดาวน์โหลดกว้าง 320px และพิมพ์บรรทัดเครดิตออกมา ไลเซนส์ที่ไม่ผ่านเกณฑ์จะถูกปฏิเสธ)
  2. วางบรรทัดนั้นใน `mockup/img/credits.js` โดย key เป็น path ใต้ `mockup/` เช่น `img/photo/x.jpg`
  3. ตั้งเป็นรูปหมวดใน `CAT_IMAGE` ของ `mockup/js/seed.js` (หรือ `product.image` สำหรับรูปสินค้า) หรือเลือกจากหน้า ข้อมูลวัสดุ › หมวดหมู่

```
node --test
```
